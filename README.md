# Heros · medva Intake — Icon Card Component

Small visual upgrade to the existing medva intake form. **One change only:**
add an icon-card component for binary (Yes / No) and 2-option (Male / Female)
questions. Everything else on the form stays as today.

## Files

- **`CHANGES.md`** — implementation spec (design tokens, CSS, SVG icons, list of questions to apply it to)
- **`index.html`** — working visual reference. Open in any browser to see the component in action.

## Quick start

1. Open `index.html` to see what the new component should look like.
2. Read `CHANGES.md` for the full implementation spec.
3. Apply to the 5 questions listed in `CHANGES.md` Section 4. Leave everything else on the form unchanged.

## Questions

Reach out to Heros if anything in the spec is ambiguous.
